# CodeAuth — AI Code Authorship Analyzer

CodeAuth is a production-grade code authorship analysis platform that determines whether source code was written by a human, generated by an AI, or composed through mixed human-AI collaboration.

Unlike superficial heuristic tools or generic LLM wrappers, CodeAuth utilizes a **trained hybrid PyTorch neural network** fusing transformer-based code representations (CodeBERT) with 41 handcrafted stylometric, structural, and complexity features.

---

## System Architecture

```
INPUT CODE
    ↓
PREPROCESSING
    ├── Tokenization (RoBERTa / CodeBERT BPE)
    ├── AST extraction (Python AST / Heuristic fallback)
    └── Code stylometric statistics
    ↓
    ┌───────────────────────┬──────────────────────────┐
    ↓                       ↓
CodeBERT Transformer    Feature Extraction (41 Dims)
768-dimensional             ↓
embedding               ┌───┼───┬───┬───┬───┐
                        ↓   ↓   ↓   ↓   ↓   ↓
                      Naming Structure Comments
                        MLP     MLP     MLP
                      Repetition Complexity Formatting
                        MLP     MLP     MLP
                            ↓
                      Feature Embeddings (6 × 16 = 96-dim)
                            ↓
                      Fusion Layer (864 → 256 → 64)
                            ↓
                        ReLU + Dropout
                            ↓
                        Classifier Head (64 → 2)
                            ↓
                        HUMAN / AI
                            ↓
                    Ablation Evidence Engine
                            ↓
                    Explainable Assessment
```

## Key Features

1. **Real ML Model Inference**: Loads trained PyTorch checkpoint `authorship_hybrid_model.pt`, `feature_scaler.pkl`, and tokenizer artifacts.
2. **41 Real Extracted Features across 6 Sub-Networks**:
   - **Naming (8)**: Identifier length, variance, snake_case ratio, camelCase ratio, uppercase ratio, single-char ratio, naming consistency.
   - **Structure (10)**: AST nodes, functions, classes, loops, conditionals, branches, returns, exception handling, nesting depth, LOC.
   - **Comments (6)**: Comment count, code ratio, length, docstrings, words, comments/function.
   - **Repetition (5)**: Duplicate lines, repeated tokens, repeated statements, repeated blocks, repetition score.
   - **Complexity (6)**: Cyclomatic complexity, max complexity, branches, loops, boolean expressions, nesting depth.
   - **Formatting (6)**: Line length, variance, indentation consistency, blank line ratio, whitespace consistency, formatting score.
3. **Ablation-Based Evidence Engine**: Real explainability derived from zeroing out feature groups and measuring prediction changes.
4. **Function-Level Mixed Authorship**: Segments code into AST blocks, runs individual inference on each block, and computes section-level human/AI distribution.
5. **Interactive Code Heatmap**: Color-coded visualization (Green = Human-associated, Red = AI-associated, Yellow = Uncertain).
6. **Repository Analysis**: Upload ZIP packages to scan full directory structures with interactive file tree status indicators.
7. **Code Evolution Analysis**: Track authorship drift across versions and detect sudden stylometric shifts.
8. **Model Evaluation Dashboard**: Upload custom CSV test datasets to generate verified empirical metrics (Accuracy, Precision, Recall, Macro F1, Weighted F1, Confusion Matrix) with zero fabrication.
9. **Reviewer Feedback System**: Human-in-the-loop expert labels and audit trails.
10. **Code Similarity Analysis**: Cosine similarity in 64-dimensional CodeBERT fusion embedding space.
11. **Agentic Repository Investigation**: Autonomous tool orchestration (`inspect_repository`, `inspect_analyses`, `get_model_prediction`) for high-level forensic summaries.
12. **Formal Audit Reports**: Generate and export audit dossiers in JSON, printable PDF, and CSV formats.
13. **Monaco Code Editor**: Professional IDE experience with multi-language syntax highlighting.
14. **Warm SaaS Design System**: Warm cream background (`#FDF6EC`), coral/orange accents (`#F97316`), smooth animations, and dark/light mode.

## Installation & Startup

### 1. Backend Setup

```bash
cd codeauth/backend

# Install dependencies
pip install -r requirements.txt

# Start backend server
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

Backend will be accessible at `http://localhost:8000`.  
Swagger API documentation: `http://localhost:8000/docs`.

### 2. Frontend Setup

```bash
cd codeauth/frontend

# Install dependencies
npm install

# Start development server
npm run dev
```

Frontend will be accessible at `http://localhost:5173`.

## Security & Ethics

- **Zero Code Execution**: Uploaded source files and code snippets are parsed statically via AST and tokenizers. CodeAuth **NEVER** executes submitted code.
- **Probabilistic Transparency**: Authorship analysis results indicate model-associated patterns and should not be treated as absolute proof of authorship.
